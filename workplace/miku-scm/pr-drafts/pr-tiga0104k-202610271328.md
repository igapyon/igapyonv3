Java 8互換のclass出力とMavenビルド設定を整備

## Overview

igapyonv3本体をJava 8互換のclassとしてビルドできるようにし、Maven依存関係とプラグイン設定を更新します。flexmark-java 0.64.8の実行にはJava 11以上が必要なため、実行環境の要件もREADMEに記載します。

## Changes

- コンパイラとJavadocの設定をJava 8に合わせ、Java 11以降の`Files.readString` / `Files.writeString`をUTF-8のbuffered I/Oに置き換えます。
- Ant、FreeMarkerおよびMavenプラグインを更新し、関連するプラグイン依存関係を明示します。
- はてな移行データのテストfixtureにPublickeyフィードを追加します。
- miku-scmのコミット操作記録（plan/request）を`workplace/miku-scm/runs/`に含めます。
